> **Asset-quality analysis of a loan book the way a bank's credit & risk team does it: NPA ratios, SMA watchlists, branch scorecards, vintage default curves, and risk segmentation — on 2,000 loans.**

⚠️ **All data is 100% synthetic** (generated by `generate_data.py` with a fixed
seed). No real bank, branch, or borrower data is used anywhere in this repo.
The branch names are fictional labels for the demo.

## What's inside

| File | What it is |
|---|---|
| `data/synthetic_loan_portfolio.csv` | 2,000 synthetic loans: branch, disbursement date, product, sanctioned/outstanding, DPD, interest rate, collateral cover, status |
| `generate_data.py` | Reproducible data generator (seeded) |
| `analyze_portfolio.py` | The full analysis — pandas, prints summary tables, saves charts |
| `charts/` | 4 output charts (PNG) |

## Methodology

1. **Delinquency staging** — every loan is bucketed by days-past-due into the
   regulatory-style ladder: Standard → SMA-0 (1–30) → SMA-1 (31–60) →
   SMA-2 (61–90) → NPA (90+).
2. **Gross NPA ratio** = NPA outstanding ÷ total outstanding (the headline
   asset-quality number).
3. **Branch scorecard** — NPA % ranked across 8 branches to spot outliers.
4. **Vintage analysis** — default rate by disbursement year, showing which
   origination cohorts went bad.
5. **Risk segmentation** — rule-based Low/Medium/High using status +
   collateral coverage (auditable, tunable — no black box).

## Key findings (synthetic data)

- **Gross NPA: 2.29%** of outstanding (₹3.56 cr of ₹155.79 cr); **SMA book at
  5.34%** — the early-warning pipeline to watch.
- **Branch outlier:** Gaya branch at ~5.7% NPA vs 0.2% at the best branch —
  a collections-review candidate.
- **Vintage:** 2019 originations default most (2.8%); 2025 book is cleanest
  (1.3%) — seasoning effect visible.
- **Product risk:** Personal (unsecured) carries the highest High-risk share
  (6.6%); Home loans the lowest (2.7%).

## How a bank / finance client would use this

- Monthly **NPA & SMA watchlist pack** for the credit committee
- **Branch scorecards** for regional managers (who needs recovery focus?)
- **Vintage curves** to tighten underwriting for weak cohorts
- **Segmentation** to prioritize collections effort and provisioning

Point this pipeline at a real core-banking extract (same columns) and it runs
unchanged.

## Run it

```bash
pip install pandas matplotlib
python3 generate_data.py      # rebuild the synthetic dataset
python3 analyze_portfolio.py  # run the analysis, charts land in charts/
```
